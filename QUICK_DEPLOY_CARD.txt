📦 STEP 1: DATABASE (5 min)
┌─────────────────────────────────────────────────────────────┐
│ 1. Go to: https://aiven.io/                                │
│ 2. Create MySQL service (Hobbyist - FREE)                  │
│ 3. Get connection details                                  │
│ 4. Create database: knowwhereyoulack                       │
│ 5. Construct DB_URL:                                       │
│    jdbc:mysql://HOST:PORT/knowwhereyoulack?sslMode=REQUIRED│
└─────────────────────────────────────────────────────────────┘

🔧 STEP 2: BACKEND (10 min)
┌─────────────────────────────────────────────────────────────┐
│ 1. Go to: https://render.com/                              │
│ 2. New Web Service → Connect GitHub                        │
│ 3. Repository: Know-Where-You-Lack                         │
│ 4. Settings:                                               │
│    - Name: knowwhereyoulack-backend                        │
│    - Branch: main                                          │
│    - Root: java-backend                                    │
│    - Build: mvn clean install -DskipTests                  │
│    - Start: java -jar target/backend-1.0.0.jar             │
│ 5. Environment Variables:                                  │
│    DB_URL=[from Aiven]                                     │
│    DB_USERNAME=avnadmin                                    │
│    DB_PASSWORD=[from Aiven]                                │
│    JWT_SECRET=YourVerySecureSecret123456                   │
│    GROQ_API_KEY=[your key]                                 │
│    PORT=8082                                               │
│ 6. Deploy and wait 10-15 min                               │
└─────────────────────────────────────────────────────────────┘

🎨 STEP 3: FRONTEND (5 min)
┌─────────────────────────────────────────────────────────────┐
│ 1. In Render: New Static Site                              │
│ 2. Same repository: Know-Where-You-Lack                    │
│ 3. Settings:                                               │
│    - Name: knowwhereyoulack-frontend                       │
│    - Branch: main                                          │
│    - Root: frontend                                        │
│    - Build: npm install && npm run build                   │
│    - Publish: dist                                         │
│ 4. Environment Variable:                                   │
│    VITE_API_URL=https://knowwhereyoulack-backend.onrender.com/api│
│ 5. Deploy and wait 5-10 min                                │
└─────────────────────────────────────────────────────────────┘
